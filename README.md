# github-achievements-lab

A small sandbox repo used to exercise GitHub profile achievements.

## What lives here

| Achievement | Requirement | Where it was exercised |
| --- | --- | --- |
| Quickdraw | Close an issue or PR within 5 minutes of opening | issue #4 (closed after 2s) |
| Pull Shark | 2+ merged pull requests | PRs #1, #2, #3 |
| YOLO | Merge a pull request without review | PR #1 |
| Pair Extraordinaire | Co-authored commit in a merged PR | PR #2 (`Co-authored-by` trailer) |
| Galaxy Brain | 2+ accepted Q&A discussion answers | discussions #5, #6, #7 |

Not reachable from a single account: **Starstruck** (16 stars), **Public Sponsor**
(paid sponsorship), **Open Sourcerer** (merged PRs across 2+ organizations).

## Notes

Badges are granted by a background job on GitHub's side, so they show up on the
profile a little while after the underlying activity.
